# Folio · 个人数字空间

专注于软件设计、个人项目与技术思考的独立数字空间。

## 项目亮点

- **极简纯静态架构**：基于 Hugo 生成，全站纯原生 HTML5 + 现代化原生 CSS，零前端框架负担，零外部 CDN 依赖。
- **卓越性能**：全站核心样式包体积仅 ~19KB，编译耗时 < 300ms，毫秒级即时加载。
- **现代化体验**：原生支持浅色 / 深色（Dark Mode）模式平滑切换与持久化存储。
- **自动化测试保障**：内置 7 项工程自动化测试，覆盖构建健康、Frontmatter 元数据、无死链排查与性能预算。

## 本地开发与预览

```bash
# 启动本地热重载预览
hugo server

# 或在 Windows 下直接双击
.\启动本地预览.cmd
```
